# 平台媒体约定

生成由对话模型调用真实托管工具, 沙箱脚本只处理已生成的本地文件.  检查当轮 image_generate, text_to_speech, video_generate, music_generate 是否存在及其 schema.  尺寸, 时长, 音色和模型选项按实际工具支持范围使用, 不承诺所有模型都有相同参数.

已授权制作任务正常推进, 不重复增加确认.  必要信息影响内容或费用时先澄清.  批量生成前可先做有代表性的样本; 重试和质量修正应有界, 保留具体失败结果.  不在失败后改用外部服务, 私人账户或云 GPU.  不索取或读取供应商 Key, token 或环境文件.

工具返回异步任务时, 使用当轮真实状态机制等待成功终态.  超时或状态未知时先核对已有任务, 不重复生成.  从成功结果取真实 localPath, 确认文件在工作区内且可读.  若工具只返回远程地址, 按平台明确提供的素材落盘机制处理; 无法取得工作区文件时报告阻塞, 不虚构路径.

回执 schema 使用 frozen dataclass 严格验证, 只接受 id, tool, status, localPath 四项.  status=completed 表示 agent 已确认原工具成功, 本地脚本本身不查询远程任务或验证计费.  保存真实工具结果作为会话证据, 不将人工写回执当成独立的平台调用证明.  后续 assets.json 保存类型, 来源工具, 文件哈希和实测媒体信息.

TTS 不等于 ASR.  优先使用工具真实返回的时间信息或用户提供的字幕, 没有词级时间戳时采用按场景配音的句级字幕, 明确其粒度.  不安装 Whisper, Piper, Torch 或模型权重来模拟平台能力.  不承诺数字人, 唇形同步, 克隆音色或外部素材库检索.

配乐仅在任务需要时生成, 时间轴明确音量和是否循环.  用户提供的视频音轨默认保留, 需要静音时在对应 clip 显式写 mute=true.  配音和原声可能重叠时应先规划混音, 不在不知情时丢弃原声.  素材来源许可和内容使用权由任务要求核对, 不把外部影像一概称为免费可用.

运行边界是 video-base 中预装的 Python 3.11+, FFmpeg/FFprobe 和可选 Remotion 工程.  不在任务中安装包或下载浏览器.  所有项目, 回执, 文件和交付物位于任务工作区.  localPath 超出工作区时使用平台正常附件落盘功能先移入工作区, 不放宽脚本路径限制.
